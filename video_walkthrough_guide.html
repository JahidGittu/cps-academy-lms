3. Data Flow & REST Architecture (Code Review)

English Speaking Script

"Let's trace how data moves from client to server.

In frontend/lib/api.ts, we configure a centralized Axios instance. Every outgoing request automatically injects the JWT Bearer token. We built a single-flight response interceptor that catches 401 errors, rotates the token via /api/auth/refresh, and retries requests transparently without logging out the student.

When a student enrolls, the frontend sends POST /api/enrollments with only { data: { course: documentId } }. On the backend in enrollment.ts, we completely ignore any client-supplied user ID to prevent spoofing. We extract caller(ctx).id directly from ctx.state.user and validate duplicate enrollments before writing to PostgreSQL."

বাংলা স্পিকিং স্ক্রিপ্ট

"এবার ডাটা ফ্লো ও রিকোয়েস্ট সাইকেল দেখে নেওয়া যাক।

ফ্রন্টএন্ডের lib/api.ts ফাইলে সেন্ট্রালাইজড এক্সিওস ইন্টারসেপ্টর কনফিগার করা আছে যা প্রতি রিকোয়েস্টে বিয়ারার টোকেন পাঠায় এবং টোকেন এক্সপায়ার হলে ব্যাকগ্রাউন্ডে রিফ্রেশ করে ইউজারকে লগআউট না করেই রিকোয়েস্ট রিট্রাই করে।

4. Backend Authorization — 3-Layer Security

English Speaking Script

"Our security is strictly enforced on the server across 3 distinct defensive layers:

Layer 1 (Bootstrap RBAC Matrix): In permissions.ts, our automated bootstrap runs on boot and syncs the 4-role permission matrix to the database. If a student attempts to POST /api/courses via Postman, Strapi immediately rejects it with a 403.

Layer 2 (Route Policies): Roles allow Instructors to edit courses, but cannot verify ownership. We wrote route policies like is-course-owner.ts and owns-parent-course.ts. Every policy returns an explicit boolean so it never fails open.

Layer 3 (Controller Scoping): In caller.ts, we apply narrow() query scoping so students can only read their own records."

বাংলা স্পিকিং স্ক্রিপ্ট

"আমাদের সিকিউরিটি ফ্রন্টএন্ডে বাটন হাইড করার ওপর নির্ভরশীল নয়; এটি ৩টি সার্ভার-সাইড লেয়ারে সুরক্ষিত:

১. permissions.ts-এ বুটস্ট্র্যাপের মাধ্যমে ডাটাবেজে ৪টি রোলের রোল-ম্যাট্রিক্স লক করা।
২. is-course-owner.ts পলিসির মাধ্যমে নিশ্চিত করা হয়েছে যাতে কোনো ইন্সট্রাক্টর অন্যের কোর্স এডিট করতে না পারে।
৩. caller.ts-এর মাধ্যমে কোয়েরি স্কোপিং করে স্টুডেন্টদের ডাটা আইসোলেশন নিশ্চিত করা হয়েছে।"

5. Dynamic Progress Calculation & Sequential Progression

English Speaking Script

"For Progress Tracking, we made two critical architectural decisions:

1. Dynamic Progress Calculation: Percentages are never stored as static columns in the database. If an instructor adds a lesson tomorrow, static values become invalid. Instead, GET /api/courses/:id/progress dynamically counts completed progress rows against total course milestones.

2. Sequential Progression: In sequence.ts, unfinishedLessonBefore() queries all earlier lessons where order < currentLesson.order. If any earlier lesson lacks a progress record, the controller returns a 403 Forbidden with the exact locked reason.

3. Quiz Milestone: Course progress only reaches 100% after the final quiz assessment is submitted and evaluated."

বাংলা স্পিকিং স্ক্রিপ্ট

"প্রগ্রেস ট্র্যাকিংয়ের ক্ষেত্রে:

১. প্রগ্রেস পার্সেন্টেজ ডাটাবেজে স্ট্যাটিক কলাম হিসেবে সেভ করা হয় না; বরং course.ts-এ ডায়নামিকালি ক্যালকুলেট করা হয় যাতে লেসন যোগ বা বিয়োগ হলেও হিসাব ১০০% সঠিক থাকে।

২. sequence.ts ফাইলে সিকোয়েনশিয়াল এনফোর্সমেন্ট তৈরি করা হয়েছে, যাতে কোনো স্টুডেন্ট আগের লেসন শেষ না করে পরের লেসনে স্কিপ করতে না পারে।"

6. Server-Side Auto-Grading & Anti-Cheat Security

English Speaking Script

"Auto-grading happens entirely on the server to eliminate client-side inspection cheating.

In question.json, the correctIndex field is configured with "private": true. Strapi's sanitizer automatically strips private fields from all Content API responses. Therefore, inspecting the Network tab in DevTools only shows questions and options — correct answers are never exposed.

When submitted, quiz-result.ts loads the private answers from PostgreSQL, calls grade.ts, computes the score, and persists the scorecard."

বাংলা স্পিকিং স্ক্রিপ্ট

"কুইজ চিটিং রোধ করার জন্য question.json-এ correctIndex-কে "private": true করা হয়েছে। ফলে ব্রাউজারের নেটওয়ার্ক ট্যাবে সঠিক উত্তর কখনোই ফাঁস হয় না।

ইউজার সাবমিট করলে সার্ভারে grade.ts দিয়ে গ্রেডিং হয়ে স্কোরকার্ড রিটার্ন করে।"

7. Admin Analytics & Cloud Media Persistence

English Speaking Script

"For platform management:

In stats.ts, the Admin overview executes parallel aggregation queries counting users per role, active courses, and quiz attempts in a single endpoint.

In middlewares.ts, we configured Content Security Policy (CSP) and CORS headers so images render smoothly across Railway and Vercel.
